# Changelog

## 0.1.0

- Native asynchronous UDP client with CRCs, request correlation and recovery.
- UI setup/reconfiguration, persistent per-entry identity and polling options.
- Twelve levels, twelve mutes, four source selectors, connectivity/address
  diagnostics, and optional Bluetooth pairing/cancel buttons.
- Raw-command action with response data and authoritative state refresh.
- Hardware captures, fake server, HA tests, HACS metadata and CI.

See README for deferred mixer, disconnect and hardware identity capabilities.
